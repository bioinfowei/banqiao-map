# 新北市板橋區 126 里歷年平均收入與所得分布互動地圖 (100~113年度)

🌐 **線上互動地圖 (GitHub Pages)**：👉 **[https://bioinfowei.github.io/banqiao-map/](https://bioinfowei.github.io/banqiao-map/)**

## 📊 專案簡介

本專案整合**財政部財政資訊中心 (FIA)** 100年度至113年度（2011–2024，共 14 個年度）之「綜合所得稅所得總額各縣市鄉鎮村里統計分析表」與**內政部國土測繪中心 (NLSC)** 官方村里界圖，提供新北市板橋區全部 **126 個里** 的互動式地理資訊與所得分布儀表板。

## ✨ 主要功能

- **🗺️ 真實板橋區 126 里地理邊界**：採用官方 TWD97/WGS84 村里界多邊形投影繪製，支援分區篩選（板橋、後埔、新板、江翠、社後、新埔、浮洲、溪崑）、滾輪縮放、拖曳平移與快速搜尋定位。
- **📅 100～113 年度跨年時間軸查詢**：支援下拉選單與時間軸滑桿切換 14 個年度，亦可開啟**自動播放**觀察板橋各重劃區與商圈 14 年間的所得演進。
- **📈 單里 14 年趨勢折線圖**：點選任一村里即可查看該里 100～113 年「平均數 vs 中位數」雙折線走勢圖與五分位距（Q1 / 中位數 / Q3）盒鬚圖。
- **↕️ 多維度互動排行表**：右下角全區 126 里排行榜支援點擊表頭或下拉選單，依**平均數、中位數、年增率%、14年累積成長%、納稅戶數、Q3/Q1 門檻、標準差**進行遞增／遞減排序。
